# Algorithms Assemble — GFG × Bennett University

An immersive, Marvel-inspired event landing page for the GeeksforGeeks Student Chapter at Bennett University.

## Concept

**Assemble across the multiverse.** Four heroes represent four ways to take part: algorithm battles, team builds, AI learning, and technical quizzes. A dark purple cinematic palette, a rotating hero wheel, glowing code trail, and scroll-led reveals make the page feel like a mission briefing. The separate Events page turns the concept into a useful event hub with a shareable Mission Pass and squad invite.

## Pages and features

- `index.html` — main landing page, hero missions, registration choices, and footer.
- `events.html` — upcoming event concepts, an endless event-card marquee, Mission Pass builder, squad invite, and draft event-day flow.
- Mission Pass names are only used in the current browser session; the page does not submit them to a server.
- Event concepts and the four-step schedule are previews. Dates, times, and registration links are not confirmed.

## Run locally

Serve this folder with VS Code Live Server and open `index.html`. An internet connection is needed for the Events page because it loads React, ReactDOM, Tailwind CSS, Babel, and Google Fonts from their CDNs.

## Submission concept blurb

Algorithms Assemble turns a student tech event into a multiverse mission briefing. Visitors rotate through four hero-led tracks, explore upcoming event concepts, and build a personalized mission pass they can download or share with their squad. The experience pairs cinematic motion with responsive layouts and clear “coming soon” labels wherever event details are still pending.
